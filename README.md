# Pooja Vangala

React + Vite fashion landing page inspired by the provided luxury home screen reference.

## Background image

Place your hero image at:

`/Users/harsha/Downloads/pooja vangala/public/herobg.png`

If you want a different filename, update `--bg-image` in:

`/Users/harsha/Downloads/pooja vangala/src/styles.css`

## Run locally

```bash
npm install
npm run dev
```
